Google Таблицы → CRM

Данные из Google Sheets загружаются через Apps Script Web App и создают заявки со статусом «Новая». Схема: Google Sheets → Apps Script → CRM.
@if (gf.syncStatus().text) {
{{ gf.syncStatus().text }}
}

Как это работает

1. Google Sheets
Заявки заполняются в таблице (вручную или через Google Form → Sheets).
2. Apps Script
Скрипт читает строки таблицы и отдаёт их как JSON по URL.
3. CRM импорт
CRM загружает JSON, создаёт клиентов и заявки, не дублирует уже импортированные.

Ожидаемые колонки таблицы

Обязательные
Імя клієнта, Телефон, Дата початку, Дата кінця
Желательные
Найменування спецтехніки, Місце розташування, Тариф грн/день
Дополнительно
Коментар, Оператор, Код техніки
