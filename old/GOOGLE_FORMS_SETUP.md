# Google Forms / Sheets -> CRM

Ответы из Google Form будут автоматически попадать в CRM как новые заявки со статусом `new`.
Самый надежный вариант: `Google Form -> Google Sheets -> Apps Script -> CRM`.

## Шаблон Google Формы (рекомендуемый)

Название формы: `Заявка на аренду спецтехники`

Добавь поля в таком порядке:

1. `Имя клиента` - Короткий ответ - обязательно
2. `Телефон` - Короткий ответ - обязательно
3. `Техника / код техники` - Короткий ответ или Выпадающий список - обязательно
4. `Дата начала` - Дата - обязательно
5. `Дата окончания` - Дата - обязательно
6. `Локация / объект` - Короткий ответ - обязательно
7. `Тариф грн/день` - Короткий ответ (число) - не обязательно
8. `Комментарий` - Абзац - не обязательно

Важно:
- Статус в форме добавлять не нужно. CRM сама создает заявку со статусом `new` ("Новое").
- Для корректного сопоставления техники лучше использовать код из CRM (например `EX-001`) в поле `Техника / код техники`.

## Как настроить

### Вариант A (автоматически, рекомендую)

1. Открой проект Apps Script и вставь код из `google-forms-app-script.js`.
2. В редакторе Apps Script запусти функцию `setupCrmGoogleForm`.
3. Подтверди доступы Google при первом запуске.
4. Функция автоматически:
   - создаст Google Form с нужными полями,
   - создаст Google Sheet для ответов,
   - привяжет Form -> Sheet,
   - сохранит `FORM_ID`, `SPREADSHEET_ID`, `SHEET_NAME` в Script Properties.
5. Проверь результат в логах/возвращаемом объекте функции: там будут URL формы и таблицы.
6. Дальше сделай деплой: `Deploy -> New deployment -> Web app`, доступ `Anyone with the link`.
7. В CRM открой `Настройки -> Google Forms`, вставь `Web app URL`, сохрани и нажми синхронизацию.

### Вариант B (вручную)

1. Создай Google Form.
2. Лучше сразу привяжи форму к `Google Sheets`:
   - `Ответы -> Связать с таблицей`
   - создай новую таблицу ответов
3. Добавь в форму поля:
   - `Имя клиента`
   - `Телефон`
   - `Техника / код техники`
   - `Дата начала`
   - `Дата окончания`
   - `Локация / объект` или `Місце розташування техніки`
   - по желанию: `Тариф грн/день`, `Комментарий`
4. Открой отдельный проект `Apps Script`.
5. Вставь код из [google-forms-app-script.js](/Users/admin/CRM/google-forms-app-script.js).
6. В начале файла укажи:
   - `SPREADSHEET_ID` для таблицы ответов
   - при необходимости `SHEET_NAME`, если лист ответов не первый
7. Нажми `Deploy -> New deployment -> Web app`.
8. Дай доступ `Anyone with the link`.
9. Скопируй `Web app URL`.
10. В CRM открой `Настройки -> Google Forms`, вставь URL и включи автозагрузку.

## Что делает CRM

- создает клиента автоматически, если его еще нет
- импортирует заявку со статусом `new` ("Новое")
- не создает дубликаты, если `responseId` уже был импортирован
- пытается сопоставить технику по `equipmentCode` или `equipmentName`
- если техника не найдена, сохраняет ее из формы в заметках заявки
- может читать ответы и напрямую из Google Form, и через Google Sheets
- для продакшена рекомендуется именно вариант через Google Sheets
